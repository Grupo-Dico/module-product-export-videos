# Product Video Export: documentación

Módulo de Grupo Dico para incluir los videos de producto en la exportación CSV multitienda de Magento.

**Estado: sin publicar.** Esta documentación describe el módulo implementado. Aún no existe una versión aceptada para producción; la [matriz de compatibilidad](guia-api-y-compatibilidad.md#plataforma-y-verificación) distingue los requisitos de las verificaciones realizadas.
